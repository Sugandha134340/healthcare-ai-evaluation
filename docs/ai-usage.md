# AI Usage Disclosure

AI-assisted development is permitted by the assessment requirements.

Tools used:
- ChatGPT: project planning, scenario design, code assistance and documentation assistance.

Validation:
- Generated code will be executed and tested locally.
- Evaluation logic will be checked against explicit scenario expectations.
- Benchmark calculations will be independently inspected.
- AI-generated assumptions will be documented and corrected when evidence from the target agent or selected healthcare application differs.
